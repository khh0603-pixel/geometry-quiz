
# 📐 幾何大師：進階複合圖形面積挑戰 (10 題)

這是一份針對圓形、梯形、長方形與正方形組合而成的進階練習題庫。適合想挑戰空間拆解與進階運算能力的學習者。

### 📝 答題須知
* **圓周率** $\pi$ 請以 **3.14** 計算。
* 若題目未給出高度，請嘗試使用 **勾股定理** $a^2 + b^2 = c^2$ 求解。
* 每一題下方皆有摺疊區塊，完成後可展開對照答案與解析。

## 🚀 挑戰題目

### 1. 內切圓殘餘面積
一個邊長為 **20 公分** 的正方形內部有一個最大的內切圓。請問正方形四個角落剩下的面積（陰影部分）總和是多少平方公分？

<details>
<summary>💡 點擊展開查看答案與解析</summary>

* **正確答案：** `86` 平方公分
* **詳細解析：**
    1.  先求出外圍正方形面積：$20 \times 20 = 400$（平方公分）。
    2.  內切圓的直徑等於正方形邊長 $20$ 公分，因此圓形半徑 $r = 10$ 公分。
    3.  求出內切圓面積：$3.14 \times 10^2 = 314$（平方公分）。
    4.  兩者相減即為四個角落剩餘的面積：$400 - 314 = 86$（平方公分）。

</details>

### 2. 等腰梯形的隱藏高度
一個等腰梯形的上底為 **10 公分**，下底為 **22 公分**，腰長（斜邊）為 **10 公分**。請問這個梯形的面積是多少平方公分？

<details>
<summary>💡 點擊展開查看答案與解析</summary>

* **正確答案：** `128` 平方公分
* **詳細解析：**
    1.  將梯形的高垂直切下，兩側形成的直角三角形底邊為：$(22 - 10) \div 2 = 6$ 公分。
    2.  利用勾股定理求出高：$\text{高} = \sqrt{10^2 - 6^2} = 8$ 公分。
    3.  帶入面積公式：$\text{面積} = \frac{(10 + 22) \times 8}{2} = 128$（平方公分）。

</details>

### 3. 重疊的葉片
在一個邊長為 **10 公分** 的正方形內，分別以兩個相鄰頂點為圓心、邊長為半徑畫兩個四分之一圓。請問這兩個四分之一圓重疊形成的「葉子」形狀面積是多少平方公分？

<details>
<summary>💡 點擊展開查看答案與解析</summary>

* **正確答案：** `57` 平方公分
* **詳細解析：**
    1.  單個四分之一圓面積：$(3.14 \times 10^2) \div 4 = 78.5$。
    2.  兩個面積總和：$78.5 \times 2 = 157$。
    3.  重疊面積 = 兩個扇形和 - 正方形面積 = $157 - 100 = 57$。

</details>

### 4. 挖空的長方形
一個長 **30 公分**、寬 **20 公分** 的長方形，在其中心挖掉一個底為 **15 公分**、高為 **10 公分** 的三角形。請問剩餘部分的面積是多少平方公分？

<details>
<summary>💡 點擊展開查看答案與解析</summary>

* **正確答案：** `525` 平方公分
* **詳細解析：**
    1.  大長方形面積：$30 \times 20 = 600$。
    2.  三角形面積：$(15 \times 10) \div 2 = 75$。
    3.  剩餘面積：$600 - 75 = 525$。

</details>

### 5. 圓環（墊圈）面積
一個環形的外部半徑為 **8 公分**，內部半徑為 **5 公分**。請問這個環形區域的面積是多少平方公分？

<details>
<summary>💡 點擊展開查看答案與解析</summary>

* **正確答案：** `122.46` 平方公分
* **詳細解析：**
    1.  大圓面積：$3.14 \times 8^2 = 200.96$。
    2.  小圓面積：$3.14 \times 5^2 = 78.5$。
    3.  相減得：$200.96 - 78.5 = 122.46$。

</details>

### 6. 長方形與半圓組合
一個長方形（長 **12**、寬 **8**）在寬邊外側連接一個半圓（直徑等於寬）。請問總面積是多少平方公分？

<details>
<summary>💡 點擊展開查看答案與解析</summary>

* **正確答案：** `121.12` 平方公分
* **詳細解析：**
    1.  長方形面積：$12 \times 8 = 96$。
    2.  半圓半徑 $r = 4$，面積：$(3.14 \times 4^2) \div 2 = 25.12$。
    3.  總面積：$96 + 25.12 = 121.12$。

</details>

### 7. 梯形逆向運算
一個梯形面積為 **120**，高為 **8**。已知下底比上底長 **10**，請問上底是多少公分？

<details>
<summary>💡 點擊展開查看答案與解析</summary>

* **正確答案：** `10` 公分
* **詳細解析：**
    1.  設上底為 $x$，下底為 $x+10$。
    2.  公式：$120 = \frac{(x + x + 10) \times 8}{2} \rightarrow 120 = (2x + 10) \times 4$。
    3.  解得 $x = 10$。

</details>

### 8. 扇形角度計算
一個扇形半徑為 **6**，面積為 **18.84**。請問其圓心角是多少度？

<details>
<summary>💡 點擊展開查看答案與解析</summary>

* **正確答案：** `60` 度
* **詳細解析：**
    1.  全圓面積：$3.14 \times 36 = 113.04$。
    2.  比例：$18.84 \div 113.04 = 1/6$。
    3.  角度：$360 \times (1/6) = 60$。

</details>

### 9. 複合 L 型面積
一個大正方形（邊長 **10**）挖掉一個角落的小正方形（邊長 **6**）。請問面積是多少平方公分？

<details>
<summary>💡 點擊展開查看答案與解析</summary>

* **正確答案：** `64` 平方公分
* **詳細解析：**
    1.  面積 = $10^2 - 6^2 = 100 - 36 = 64$。

</details>

### 10. 中點內接正方形
邊長為 **14** 的正方形，連接四邊中點形成一個內接正方形。請問其面積是多少平方公分？

<details>
<summary>💡 點擊展開查看答案與解析</summary>

* **正確答案：** `98` 平方公分
* **詳細解析：**
    1.  內接正方形面積剛好是原正方形的一半。
    2.  計算：$(14 \times 14) \div 2 = 196 \div 2 = 98$。
