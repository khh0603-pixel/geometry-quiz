# 📐 幾何大師：進階複合圖形面積挑戰 (10 題)

這是一份針對圓形、梯形、長方形與正方形組合而成的進階練習題庫，適合國中幾何複習。

---

### 📝 答題須知
* **圓周率**：請以 **3.14** 計算。
* **重點知識**：包含勾股定理、割補法、圓面積公式。
* **操作說明**：點擊 **💡 解析與答案** 即可展開內容。

## 🚀 挑戰題目

### 1. 內切圓殘餘面積
一個邊長為 **20 公分** 的正方形內部有一個最大的內切圓。請問正方形四個角落剩下的面積（陰影部分）總和是多少平方公分？

<details>
<summary>💡 解析與答案</summary>

* **正確答案**：86 平方公分
* **詳細步驟**：
    1. 正方形面積：20 * 20 = 400
    2. 圓形半徑：20 / 2 = 10
    3. 圓面積：3.14 * (10 * 10) = 314
    4. 剩餘面積：400 - 314 = 86
</details>

### 2. 等腰梯形的隱藏高度
一個等腰梯形的上底為 **10 公分**，下底為 **22 公分**，腰長（斜邊）為 **10 公分**。請問這個梯形的面積是多少平方公分？

<details>
<summary>💡 解析與答案</summary>

* **正確答案**：128 平方公分
* **詳細步驟**：
    1. 求底邊三角形之底：(22 - 10) / 2 = 6
    2. 利用勾股定理求高 (h)：
    $$h = \sqrt{10^2 - 6^2} = \sqrt{100 - 36} = 8$$
    3. 梯形面積公式：(10 + 22) * 8 / 2 = 128
</details>

### 3. 重疊的葉片
在一個邊長為 **10 公分** 的正方形內，分別以兩個相鄰頂點為圓心、邊長為半徑畫兩個四分之一圓。請問重疊形成的「葉子」形狀面積是多少平方公分？

<details>
<summary>💡 解析與答案</summary>

* **正確答案**：57 平方公分
* **詳細步驟**：
    1. 單一四分之一圓面積：(3.14 * 10 * 10) / 4 = 78.5
    2. 兩個四分之一圓總和：78.5 * 2 = 157
    3. 扣除重複計算的正方形：157 - 100 = 57
</details>

### 4. 挖空的長方形
一個長 **30 公分**、寬 **20 公分** 的長方形，在其中心挖掉一個底為 **15 公分**、高為 **10 公分** 的三角形。請問剩下的面積是多少平方公分？

<details>
<summary>💡 解析與答案</summary>

* **正確答案**：525 平方公分
* **詳細步驟**：
    1. 長方形面積：30 * 20 = 600
    2. 三角形面積：(15 * 10) / 2 = 75
    3. 剩餘面積：600 - 75 = 525
</details>

### 5. 圓環面積
一個環形的外部半徑為 **8 公分**，內部半徑為 **5 公分**。請問這個環形的面積是多少平方公分？

<details>
<summary>💡 解析與答案</summary>

* **正確答案**：122.46 平方公分
* **詳細步驟**：
    1. 外圓面積：3.14 * 8 * 8 = 200.96
    2. 內圓面積：3.14 * 5 * 5 = 78.5
    3. 環形面積：200.96 - 78.5 = 122.46
</details>

### 6. 長方形與半圓組合
一個長方形（12x8）在寬度 8 公分的那一側連接一個半圓。請問總面積是多少平方公分？

<details>
<summary>💡 解析與答案</summary>

* **正確答案**：121.12 平方公分
* **詳細步驟**：
    1. 長方形面積：12 * 8 = 96
    2. 半圓半徑：8 / 2 = 4
    3. 半圓面積：(3.14 * 4 * 4) / 2 = 25.12
    4. 總面積：96 + 25.12 = 121.12
</details>

### 7. 梯形逆向運算
一個梯形面積為 **120**，高為 **8**。下底比上底長 **10**，請問上底是多少公分？

<details>
<summary>💡 解析與答案</summary>

* **正確答案**：10 公分
* **詳細步驟**：
    1. 設上底為 x，下底為 x + 10
    2. 依公式列式：((x + x + 10) * 8) / 2 = 120
    3. 計算：(2x + 10) * 4 = 120  => 2x + 10 = 30  => x = 10
</details>

### 8. 扇形角度計算
一個扇形半徑為 **6**，面積為 **18.84**。請問其圓心角是多少度？

<details>
<summary>💡 解析與答案</summary>

* **正確答案**：60 度
* **詳細步驟**：
    1. 全圓面積：3.14 * 6 * 6 = 113.04
    2. 扇形佔圓比例：18.84 / 113.04 = 1/6
    3. 圓心角：360 * (1/6) = 60 度
</details>

### 9. 複合 L 型面積
一個大正方形（10x10）在右上角挖掉一個小正方形（6x6）。請問面積是多少？

<details>
<summary>💡 解析與答案</summary>

* **正確答案**：64 平方公分
* **詳細步驟**：
    1. 大面積：10 * 10 = 100
    2. 小面積：6 * 6 = 36
    3. 剩餘面積：100 - 36 = 64
</details>

### 10. 中點內接正方形
邊長為 **14** 的正方形，連接四邊中點形成一個新的正方形。請問新正方形面積是多少平方公分？

<details>
<summary>💡 解析與答案</summary>

* **正確答案**：98 平方公分
* **解題關鍵**：中點連線正方形面積為原面積的 1/2。
* **計算方式**：(14 * 14) / 2 = 196 / 2 = 98
</details>
