📐 幾何大師：進階複合圖形面積挑戰 (10 題)
這是一份針對圓形、梯形、長方形與正方形組合而成的進階練習題庫。適合想挑戰空間拆解與進階運算能力的學習者。
> **注意事項：** > * 圓周率 $\pi$ 請以 $3.14$ 計算。
> * 若題目未給出高度，請嘗試使用勾股定理 $a^2 + b^2 = c^2$ 求解。
---
Q1. 內切圓殘餘面積
一個邊長為 $20$ 公分的正方形內部有一個最大的內切圓。請問正方形四個角落剩下的面積（陰影部分）總和是多少平方公分？
Q2. 梯形的隱藏高度
一個等腰梯形的上底為 $10$ 公分，下底為 $22$ 公分，腰長（斜邊）為 $10$ 公分。請問這個梯形的面積是多少平方公分？
Q3. 重疊的葉片
在一個邊長為 $10$ 公分的正方形內，分別以兩個相鄰頂點為圓心、邊長為半徑畫兩個四分之一圓。請問這兩個四分之一圓重疊形成的「葉子」形狀面積是多少？
Q4. 挖空的長方形
一個長 $30$ 公分、寬 $20$ 公分的長方形，在其中心挖掉一個底為 $15$ 公分、高為 $10$ 公分的三角形，請問剩餘部分的面積是多少？
Q5. 圓環（墊圈）面積
一個環形的外部半徑為 $8$ 公分，內部半徑為 $5$ 公分。請問這個環形區域的面積是多少？
Q6. 長方形與半圓組合
一個組合圖形由一個長方形（長 $12$ 公分、寬 $8$ 公分）組成，並在寬邊的外側連接一個半圓（半圓直徑等於長方形的寬）。請問總面積是多少？
Q7. 梯形逆向運算
一個梯形的面積為 $120$ 平方公分，高為 $8$ 公分。已知下底比上底長 $10$ 公分，請問上底是多少公分？
Q8. 扇形角度計算
一個扇形的半徑為 $6$ 公分，其面積為 $18.84$ 平方公分。請問這個扇形的圓心角是多少度？
Q9. 複合 L 型面積
一個 L 型圖形可以看作是一個大正方形（$10 \times 10$）在其角落挖掉一個小正方形（$6 \times 6$）。請問這個 L 型圖形的面積是多少？
Q10. 中點內接正方形
一個邊長為 $14$ 公分的正方形，連接其四個邊的中點形成一個小的內接正方形。請問這個內接正方形的面積是多少？
---
🔑 答案與解析

86 $cm^2$：$20^2 - (3.14 \times 10^2) = 400 - 314 = 86$。
128 $cm^2$：先求高 $\sqrt{10^2 - 6^2} = 8$。面積 = $(10+22) \times 8 \div 2 = 128$。
57 $cm^2$：兩個四分之一圓和減去正方形 = $(100 \times 3.14 \div 2) - 100 = 157 - 100 = 57$。
525 $cm^2$：$600 - (15 \times 10 \div 2) = 600 - 75 = 525$。
122.46 $cm^2$：$3.14 \times (8^2 - 5^2) = 3.14 \times 39 = 122.46$。
121.12 $cm^2$：長方形 $96$ + 半圓 $(3.14 \times 4^2 \div 2) = 96 + 25.12 = 121.12$。
10 $cm$：設上底 $x$，$(x + x + 10) \times 8 \div 2 = 120 \rightarrow 8x + 40 = 120 \rightarrow x = 10$。
60 度：全圓面積 $113.04$。比例 $18.84 / 113.04 = 1/6$。$360 \div 6 = 60$。
64 $cm^2$：$100 - 36 = 64$。
98 $cm^2$：內接正方形面積為原正方形的一半 = $196 \div 2 = 98$。
