1. 正方形與內切圓
一個邊長為 $20$ 公分的正方形內部有一個最大的內切圓。請問正方形四個角落剩下的面積（陰影部分）總和是多少？
公式提示： $A = L^2 - \pi r^2$
2. 等腰梯形求高

解題重點： 需先利用勾股定理 $a^2 + b^2 = c^2$ 求出高。
